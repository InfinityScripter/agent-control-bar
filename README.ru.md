# Claude Control Bar

[English](README.md) | Русский

Приложение для строки меню macOS, которое следит за Claude Code и OpenAI Codex. Показывает, какие сессии работают, какие ждут вашего ответа, сколько контекста и лимитов израсходовано. Из панели можно вернуться к сессии или включить и выключить MCP-серверы и инструменты.

<img src="docs/screenshots/menu-bar.png" alt="Claude и Codex рядом в строке меню: у каждого своя иконка, состояние, таймер и полоски лимитов" width="680">

В режиме **Both** у Claude и Codex отдельные блоки в строке меню. Состояние, таймер и лимиты у каждого свои; клик по любому блоку открывает общую панель.

На скриншотах сборка из `main` с демонстрационными сессиями и примерными значениями. DMG содержит изменения своего релиза; для более новых правок из исходников нужен новый выпуск.

## Установка

Нужны macOS 13+, Node.js, системный `/usr/bin/python3` и Claude Code или Codex. Плагину нужны Claude Code и Xcode Command Line Tools. В DMG приложение уже собрано; этот способ подходит и тем, кто пользуется только Codex.

### Плагин Claude Code

Выполните команды внутри Claude Code:

```bash
/plugin marketplace add InfinityScripter/agent-control-bar
```

```bash
/plugin install claude-control-bar
```

При следующем старте сессии приложение соберётся на вашем Mac. Если Command Line Tools ещё нет, установите их командой `xcode-select --install`; первая сборка может занять несколько минут. Обновления плагина приходят через Claude Code.

### DMG

1. Скачайте `claude-control-bar.dmg` из [последнего релиза](https://github.com/InfinityScripter/agent-control-bar/releases/latest).
2. Перетащите Claude Control Bar в «Программы».
3. Запустите приложение один раз, чтобы установить хуки, затем откройте новую сессию Claude Code или Codex.

DMG не нотаризован. Если macOS блокирует первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** или выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/Claude Control Bar.app"
```

Выберите один способ установки. Если установлены оба, хуками управляет плагин.

## Первая сессия

Найдите иконку рядом с часами в строке меню. Кликните по ней, чтобы открыть **Sessions** и **MCP**; лимиты видны над обеими вкладками. Для настроек нажмите **Settings** внизу или ⌘,. Иконка в Доке появляется только пока это окно открыто.

Хуки сессий запускают приложение автоматически. Оно остаётся открытым, пока видит активные сессии или процессы агентов, а также пока открыты его панель или настройки. Если запустить его вручную без активной сессии, оно может закрыться после установки хуков.

После установки откройте новую сессию. Уже открытая сессия Claude Code может появиться после следующего промпта или вызова инструмента. При установке плагином сначала дождитесь сборки. Ошибки сборки записываются в `~/.claude/control-bar/problems.log`.

### Подтвердите хуки Codex

Установка добавляет восемь хуков в `~/.codex/hooks.json`, сохраняя остальные записи. Codex запускает их только после подтверждения. До этого приложение не получает состояние сессий Codex и показывает в панели уведомление о хуках. Собственные файлы сессий Codex при этом продолжает писать.

Нажмите **Approve** в уведомлении или в **Settings → General → Codex**. Подтвердить хуки можно и на экране проверки самого Codex. **What gets approved** показывает `~/.codex/hooks.json` в Finder, чтобы вы могли сначала прочитать команды. Приложение просит Codex подтвердить только свои записи и только после вашего клика.

**Settings → About → Install hooks again** восстанавливает установку; доверие к хукам подтверждается отдельно. Чтобы удалить их, следуйте [инструкции по удалению](#удаление) ниже.

<details>
<summary>Что делают хуки Codex</summary>

Хуки запускают два локальных скрипта, `~/.claude/control-bar/update.js` и `lifecycle.js`, при старте и завершении сессии, отправке промпта, вызове инструмента, запросе разрешения, остановке и прерывании.

| Действие | Что происходит |
| --- | --- |
| Чтение | Payload хука, начало и конец rollout-файла этой сессии: где она запущена и сколько токенов использует. |
| Запись | Небольшие файлы состояния и диагностические маркеры в `~/.claude/control-bar/codex/`. |
| Запуск команд | `git status --porcelain` для числа незакоммиченных файлов, `pgrep` для проверки приложения и `open -g -b …` для его запуска. |
| Отправка данных | Сетевых запросов нет. Скрипты используют встроенные модули Node без npm-зависимостей. |

Подробнее о файлах и правах: [PRIVACY.md](PRIVACY.md).

</details>

## Сессии: состояние и переход к работе

<img src="docs/screenshots/sessions.png" alt="Панель с лимитами Claude и Codex, разными состояниями сессий и раскрытой строкой Codex с моделью и контекстом" width="430">

Жёлтая точка отмечает сессию, которая ждёт разрешения или ответа. Раскройте строку, чтобы увидеть модель и контекст. Codex сохраняет полный идентификатор модели, например `gpt-6.1-sol`.

| Состояние | Что видно |
| --- | --- |
| Idle | Отдыхающая иконка или питомец. |
| Думает или выполняет инструмент | Анимированная иконка, текущая работа и время хода. |
| Needs you | Жёлтая точка и иконка или питомец в ожидании. |

В каждой строке видны проект и ветка, таймер хода и заполненность контекста, если эти данные доступны. Таймер считает текущий ход, а не всю сессию. Если выключить **Timer in menu bar**, таймеры в строках останутся.

Клик по строке возвращает к её терминалу или редактору. Для десктопных сессий Codex приложение открывает разговор по ссылке `codex://threads/`, если она доступна. Обычно клик по терминальной сессии просто выводит её приложение на передний план. **Settings → General → Exact terminal focus** открывает нужные окно и вкладку в Terminal или iTerm. Эта настройка по умолчанию выключена и требует разрешения macOS на автоматизацию.

## Лимиты

Полоски показывают израсходованный процент. Для Claude видны окна на 5 часов и 7 дней, а на планах, где он есть, ещё и отдельный недельный лимит Fable. Время сброса видно в панели. Длительность окон Codex берётся из его данных: это не всегда пара «5 часов и неделя».

Codex может сообщать об обычном и резервном пулах. Строка меню предпочитает обычный. Если доступны только данные резервного, она показывает их и поясняет это в подсказке. В панели видны все полученные пулы. Если у провайдера нет пригодных данных, его полоски лимитов не появляются; цифры другого провайдера вместо них не подставляются.

После указанного времени сброса окно показывает 0% до нового измерения, а старый отсчёт сбрасывается. Снимки Codex, по которым нельзя определить срок окна, не отображаются.

В **Settings → Appearance → Limits strip** режим **Two rows** показывает обоих провайдеров одновременно. **Switcher** отдаёт всю ширину одному; второй остаётся за вкладкой с тонким индикатором использования под названием.

Лимиты Claude приходят из API Anthropic с OAuth-токеном, который Claude Code хранит локально. Выключите **Limits via Anthropic API** в General, чтобы остановить опрос. Лимиты Codex читаются из локальных rollout-файлов в `~/.codex/sessions`; **Codex limits** выключает это чтение. Токен OpenAI и запрос к его API для этого не нужны.

## MCP-серверы и инструменты

<img src="docs/screenshots/mcp.png" alt="Вкладка MCP: раскрытый сервер Claude с переключателями инструментов и отдельная группа серверов Codex" width="430">

Раскройте сервер, чтобы увидеть его инструменты. У каждого сервера и инструмента есть свой переключатель: можно оставить сервер доступным, но убрать ненужные инструменты. Claude и Codex показаны отдельными группами.

Claude Code получает изменённый набор инструментов в новых сессиях. Изменения Codex сохраняются в его конфигурации MCP; если текущий разговор сохраняет старый список инструментов, откройте новую сессию.

**Check MCP now** (⌘R) обновляет состояние серверов и число инструментов. **Open settings.json** открывает файл настроек Claude. Его переключатели сохраняются в этом файле с резервными копиями; переключатели Codex меняют его собственную конфигурацию MCP.

Проверка запускает настроенные MCP-серверы и запрашивает их инструменты. Удалённые серверы могут получать подключения. Если поиск серверов Codex работает медленно, выключите **Codex MCP servers** в General. Когда сервер падает или возвращается, приложение отправляет уведомление macOS; строка **Notifications are off** открывает нужную страницу Системных настроек.

## Что показывать в строке меню

<img src="docs/screenshots/settings-general.png" alt="Страница General: выбор Show, таймер и слова состояния, настройки лимитов и подтверждение хуков Codex" width="820">

**Settings → General → Show** управляет строкой меню и содержимым панели:

| Show | Результат |
| --- | --- |
| Claude Code | Иконка, состояние, таймер и лимиты Claude; его сессии и MCP-серверы в панели. |
| Codex | Те же данные и управление для Codex. |
| Both | Два независимых блока в одном элементе строки меню, оба агента в общей панели. |
| Hidden | Только иконка для открытия панели. Панель и звуки по-прежнему работают с обоими агентами. |

Пока вы не выбрали режим, приложение включает Codex, если он установлен. **Thinking words** заменяет *Thinking…* словами из спиннера Claude Code, например *Manifesting…*. Оба блока учитывают настройки таймера и текста.

В окне настроек пять страниц: General, Appearance, Motion, Sounds и About. В General также находятся управление лимитами, поиск MCP-серверов, подтверждение хуков и анонимный запрос статистики. В About можно проверить обновления и восстановить хуки.

## Иконки, питомцы и звуки

<img src="docs/screenshots/settings-appearance.png" alt="Страница Appearance с превью иконок строки меню, отдельным выбором питомцев Claude и Codex и раскладкой лимитов" width="820">

Иконка Claude выбирается в **Settings → Appearance → Menu bar icon**: Crab Walking, Claude Spark, спиннер Claude Code или питомец. В **Color** доступны Orange и System; питомцы сохраняют свои цвета. Отдельный выбор **Session rows** меняет иконки строк Claude. **Codex icon and session rows** выбирает питомца и для блока Codex в строке меню, и для его сессий. **None** возвращает обычные индикаторы в строках.

Краб по умолчанию считает работающие сессии: спит при нуле, курит сигару при одной, ходит при двух или трёх, потеет при четырёх или пяти, а при шести и больше у него загорается голова. Бездействующие сессии не считаются. Когда нужен ваш ответ, краб поднимает табличку с вопросительным знаком. У питомцев три состояния: отдых, работа и ожидание.

Clawd, краб, поставляется с приложением. В выборе также появляются питомцы из `~/.codex/pets` и маскоты десктопных приложений Codex или ChatGPT. После добавления питомца заново откройте Settings; перезапуск не нужен. Если выбранное изображение исчезнет, в строке меню Claude вернётся к крабу, а Codex к своему символу; выбор сохранится.

**Motion** управляет переходами панели и питомцами в строках сессий. Off останавливает эти анимации, Subtle (по умолчанию) оживляет элементы управления, а Expressive добавляет появление строк. Системный Reduce Motion ограничивает движение и оставляет питомцев панели неподвижными. Анимации состояния в строке меню продолжают работать; питомцы панели двигаются только пока она открыта.

В **Sounds → When a turn finishes** можно включить звук после каждого хода или только после ходов дольше 1, 5 или 15 минут; по умолчанию он выключен. **When Claude needs you** управляет звуком ожидания для обоих агентов. Он не звучит, если терминал или приложение этой сессии уже на переднем плане. На выбор Off, Tink, Purr, Ping, Glass, Hero и Submarine; при выборе звука проигрывается превью.

Звуки следуют выбору **Show**. В Both и Hidden они работают с обоими агентами.

## Приватность

Состояние сессий, контекст и лимиты Codex читаются локально. Приложение не отправляет ваши разговоры или пути проектов разработчику. Хуки не делают сетевых запросов.

Само приложение проверяет обновления, может запрашивать лимиты Claude у Anthropic и подключаться к вашим MCP-серверам. Анонимный запрос статистики включён по умолчанию: не чаще раза в день, первый запрос через 24 часа после первого запуска. В нём версия приложения, основная версия macOS, архитектура процессора и способ установки; идентификатора устройства нет. Выключите **Anonymous usage ping** в General или задайте в окружении приложения `CONTROL_BAR_NO_ANALYTICS` с любым значением.

В [PRIVACY.md](PRIVACY.md) перечислены сетевые запросы, локальные файлы, права и поведение отладочных логов.

## Обновления и команды Claude Code

Плагин обновляется через Claude Code. При установке из DMG нажмите карточку **Update available** в панели, прочитайте изменения и выберите **Download and install**. Приложение проверит SHA-256 загруженного файла по данным GitHub, заменит себя и перезапустится. **Settings → About → Check now** запускает проверку вручную. История версий — в [CHANGELOG.md](CHANGELOG.md).

Плагин добавляет две команды внутри Claude Code:

- `/mcp-health` выводит состояние серверов, число инструментов, отключённые инструменты, контекст сессий и лимиты.
- `/limits-capture install|uninstall|status` по желанию оборачивает команду `statusLine`, чтобы читать лимиты, которые передаёт Claude Code. `uninstall` восстанавливает прежнюю команду.

## Удаление

Если установили плагином, выполните `/plugin uninstall claude-control-bar`, затем переместите `~/Applications/Claude Control Bar.app` в Корзину.

Если установили из DMG, сначала удалите хуки:

```bash
node "/Applications/Claude Control Bar.app/Contents/Resources/uninstall.js"
```

Затем переместите приложение в Корзину. Если оно установлено в другой папке, измените путь в команде. Скрипт сохраняет чужие хуки и по возможности восстанавливает прежнюю команду `statusLine`. Само приложение и его папку данных, `~/.claude/control-bar/`, он не удаляет.

## Если иконки нет

Выполните `pgrep -x ClaudeControlBar`. PID означает, что приложение работает; проверьте, оставляют ли другие элементы строки меню ему место. Если вывода нет, оно не запущено: откройте новую сессию и проверьте `~/.claude/control-bar/problems.log`. Для Codex также проверьте подтверждение хуков в General.

Другие решения, настройки раскладки и диагностика: [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
