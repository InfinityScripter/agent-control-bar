**Требования:** R01, R01.1, R01.2, R01.3, R04, R07, R08, R09i

**Зона:** `scripts/mcpbar.py` (раздел statusLine, `STRINGS`, диспетчер `main`) · `tests/test_mcpbar.py` · `Sources/Model/BackendCommand.swift` · `Sources/main.swift` · `Sources/HookSetup.swift` · `tests/model/main.swift` · `CHANGELOG.md` · `PRIVACY.md` · `TROUBLESHOOTING.md`
**Волна:** 1
**Ревью:** да — правка файла пользователя (`~/.claude/settings.json`)
**Модель:** сильная

## Что должно заработать

Пользователь обновил приложение, и оно переименовалось. Команда `statusLine` в его `settings.json` всё ещё указывает на обёртку по старому пути, которого нет. При следующем запуске приложение само находит свою мёртвую обёртку и перепривязывает её на живой файл рядом с работающим бэкендом. Всё остальное в `statusLine` (`padding`, `refreshInterval`, внутренняя команда пользователя) остаётся как было. Чужая статусная строка не трогается никогда. Если обёртка жива, запуск ничего не переписывает. Если `settings.json` в этот момент нечитаем или занят, починка просто откладывается до следующего запуска.

## Критерии приёмки

- [ ] `mcpbar.py statusline --heal` при нашей команде с мёртвым путём обёртки переписывает `statusLine.command` на `bash "<живая обёртка>"`, сохраняет прочие поля объекта, обновляет `statusline-installed.json`, делает бэкап `settings.json` как установка
- [ ] внутренняя команда пользователя (`statusline-inner-command`) и `statusline-saved.json` не меняются
- [ ] чужая команда (живая или мёртвая, без наших сайдкаров) не трогается: файл настроек байт в байт прежний, бэкапа нет
- [ ] живая наша обёртка: без записи, без бэкапа, ответ «alive»
- [ ] нечитаемый `settings.json` → ответ «busy», файл не тронут
- [ ] отсутствие `statusLine` вовсе → без изменений
- [ ] мёртвая обёртка прошлой версии без `statusline-installed.json`, но с другими сайдкарами, тоже чинится (ветка `statusline_ours` пункт 5)
- [ ] `BackendCommand.statuslineHeal.arguments == ["statusline", "--heal"]`, слово в `backendGolden`
- [ ] `StatusController.init` после `checkHooks()` вызывает `runQuietCommand(.statuslineHeal)` только для установленной копии (`isInstalledCopy`), один раз за запуск
- [ ] тесты Python зелёные, Node зелёные, Swift-модель зелёная, `swiftc -typecheck` всего приложения проходит
- [ ] `CHANGELOG.md`: секция `## [Unreleased]` с пунктом в `### Fixed`; `PRIVACY.md` — починка `statusLine` при запуске (что читается, что пишется, бэкап); `TROUBLESHOOTING.md` — «статусная строка пропала после обновления»
