## Что должно заработать
Закрытый терминальный клиент Codex перестаёт удерживать запись из-за живого общего daemon. Пользователь может убрать запись из раскрытой карточки; новая активность возвращает её. Версия 0.27.2 готова к сборке и публикации.

## Критерии приёмки
- [ ] Регрессия воспроизводит живой daemon с закрытым CLI; после фикса запись и Needs you исчезают.
- [ ] Живой долгий CLI остаётся; reused tty с более новым процессом не удерживает старую запись; неполный/ошибочный probe не удаляет запись; остальные поверхности сохраняют правила.
- [ ] Remove from list в раскрытой карточке убирает только выбранную запись и lead/counter, без kill/изменения истории.
- [ ] Скрытие сохраняется при рестарте; реальная новая активность возвращает запись; устаревшее нажатие не прячет более свежую активность, ошибка сохранения видима.
- [ ] Проверки фиксируют реальные эффекты, включая persistence failure/provider isolation. Полные Node/Python/Swift проверки проходят.
- [ ] Сохранена старая функциональность; новый код следует existing Swift model/controller architecture без новых зависимостей.
- [ ] Описание поведения обновлено; версия manifest 0.27.2 и CHANGELOG. Build universal/DMG выполняет orchestrator после реализации.
- [ ] Root проводит живую проверку кнопки/real orphan, clean-clone acceptance и выпуск после зелёных CI; worker не публикует.
