# Границы нативной проверки

REA-захват реального окна отклонён автоматической проверкой разрешений: окно может содержать названия сессий и локальные пути. Повторное получение реального окна другими каналами не выполняется.
Для безопасной проверки подготовлен отдельный процесс и отдельный CFFIXED_USER_HOME с вымышленными сессиями. Маленький native probe подтвердил изменение NSHomeDirectory; AXIsProcessTrusted=true.
REA для synthetic barebinary вернул capability_unavailable/process-identity-unavailable (не удалось получить launch time). Повторов нет; проверка синтетического окна будет через локальный AX API. Реальный orphan проверяется только по минимальным служебным данным, без полного снимка пользовательского окна.

Native UI ограничена также блокировкой экрана: CGSSessionScreenIsLocked=1. AX/screenshot не работают даже на простом контроле. Настоящий путь PanelStore→Actions→Board→atomic persistence проверен на synthetic home; unmodified production binary подтверждает сохранение после restart и восстановление новымhook. Пользователю асинхронно предложено разблокировать Mac для клика по synthetic окну; до ответа никаких попыток обходить lock.
